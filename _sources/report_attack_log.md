# Attack Log (Table View)

![Attack Chart](chart4.png)

Cette **table de données** liste **toutes les attaques** avec leurs informations essentielles 
- **ip_address** : la source de l'attaque
- **src_port** : le port source
- **dest_port** : la cible
- **app_proto** : le protocole applicatif (telnet, smb, etc.)
- **event_count** : le nombre d'attaques agrégées pour chaque combinais.
